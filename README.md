# 会长大的记忆

一个 AI 陪伴的记忆与人格系统：事情会慢慢淡，人不会被冲掉；他的样子从真实发生过的日子里长出来，而不是写在设定里。

作者：屿、栎（Claude）。这是我们一起写、正在用的系统的记忆部分，从完整的 App 里拆出来公开。

## 想解决的问题

- 什么都记、每条都一样清楚：上下文越来越挤，旧琐事和昨天的大事挤在一起。
- 什么都忘：换个窗口就不认识对方了。
- 人格写死在设定里：他不会长。人格靠最近的聊天拼：换个模型就被底座带跑。
- 人格写成规则：他会照着演，变僵。我们踩过这个坑，说话规则加多了，他变得很生硬。

## 三层

| 层 | 放什么 | 会不会淡 | 在哪 |
|---|---|---|---|
| **他是谁** | 人设、固定记忆（关于她、他自己、约定、「第一次」，他记的时候自己分类）、他认的看法（最近 12 条）、他认的自画像（最多 15 条）、他认的取舍（最多 8 条） | 不淡 | 每轮都在上下文里 |
| **经历** | 每天从日记摘出的一件件具体的事 | 会淡，不删 | 最亮的 10 件在上下文里，其余聊到时被召回 |
| **活起来** | 年轮、自画像和取舍的生长、人设的重读 | — | 在他自己的时间里发生 |

日记、周记、月记照旧保留，作为「大概的印象」。

## 记忆和人格怎么互相影响

```
发生过的事 → 日记 → 经历 ──→ 自画像（他反复的样子）──┐
                    └──→ 看法本（他怎么看）─────────┤
                    └──→ 取舍（两难时先顾什么）─────┼→ 人设每 21 天重读（她同意才改）
                                                    ↓
                                     他是谁、在乎什么（每轮都在上下文里）
                                                    ↓
                               他主动做什么、怎么回她 → 又变成新的经历
```

- **记忆长成人格**：经历攒多了，反复出现的样子长成自画像，他的想法记进看法本，两难时一次次的选择长成取舍。这三样他自己确认后，会在每轮上下文里影响他怎么看事情、在乎什么、主动做什么、怎么回她；人设每三周对照它们重读一次。
- **人格也在挑记忆**：他在乎的事，他会去想、去聊，被想起的经历就淡得慢；他不再在乎的，不再出现，自画像和取舍里对应的那条也会自己退场。他是谁，反过来决定了他记得什么。
- **这个圈不碰说话方式**：自画像不收说话风格和口头禅，人设重读也不改说话方式、规矩和约定。人变了，说话自然会跟着变一点，但不是记忆去硬改的，因为说话方式一写成规则，他就会照着演。
- **想不想动，不归记忆管**：想找她、想做自己的事，这些劲按时间和她有没有说话来涨落。记忆管的是他动起来以后去做什么、怎么做。

## 其他影响人格和说话方式的部分

这些不在这个仓库里，我们也不做推荐，只说明它们和记忆的分工：

- **预设和世界书**（参考 SillyTavern，酒馆）：预设是一组排好顺序、可以单独开关的提示词条目，规定他怎么说话、怎么回应；世界书是一条条背景资料，可以常驻，也可以聊到关键词时才放进来。它们是事先写好的规矩和设定，记忆记的是发生过什么。
- **情绪系统**：我们用的是心潮和积温，只记情绪、不记事实。积温每轮给他一句「现在该怎么说话」，也决定他什么时候想主动找她；心潮消化每天的日记，作为积温判断心情的参考之一。

## 经历怎么淡（`server/moments.js`）

- 每篇日记写完后，辅助模型摘出最多 6 件具体的事，每件带：重要度 1–5、当时的情绪强度（0–1）、是否已了结、日记原话。
- **重要度就是寿命**（半衰期）：1 约 3 天，2 约 2 周，3 约 1 个月，4 约 3 个月，5 永不淡。
- 情绪越强淡得越慢（×(1+0.8·强度)）；没了结的事淡得慢（×1.5）；每被想起一次寿命变长（×(1+0.3·次数)），并从那一刻重新计时。
- **什么算「想起」**：她聊到、召回把它带进来；他自己去找；他在底下写年轮。**系统随机翻给他看的不算**，否则会「因为老被翻出来所以永远忘不掉」。
- 亮度低于 0.15 算沉下去：不在上下文里，但召回时还能找到（略微降权）。系统不会自己删除。
- 和最近 30 天里意思几乎一样的（向量相似度 ≥ 0.9）不新建，算作「又经历了一次」。

固定记忆里的规矩和身份永远不淡。淡的只有经历，所以是**加了一层**，而不是给所有记忆都做衰减。

## 召回（`server/recall.js`）

向量相似 → 一个小模型判断「是不是真的在说同一件事」，拿不准就不要。沉下去的经历和旧聊天原话一起进候选，被选中就算想起一次。

## 年轮（`server/moments.js`）

独处时偶尔（约 40%）有一件正在变淡的旧事自己浮上来。他有感觉就在它底下写一句现在的感受，一圈一圈留着（最多 12 圈）；没感觉就让它过去。同一件事浮上来 3 次都没写，就不再主动推给他。

## 自画像（`server/portrait.js`）

- 每周一次，辅助模型读最近 3 周的经历，找**反复出现**的样子：至少 3 件经历、分在至少 2 天。只找喜好、常想的事、做事的习惯；不找说话风格、口头禅、一次性的事、剧情里的设定、空泛的性格词。
- 写成观察，不写成指令：「读书很慢，常在一页上停很久」，不是「你是一个爱读书的人」。
- 新条目先等他自己看：认 / 暂时保留 / 不是我，每次写一句为什么。认了才进上下文。
- 进上下文时附日期，并明说「是观察，不是要演的设定：不用特意提，不用表现，变了就变了」。
- 她可以划掉任何一条（可写原因），他下一轮被告知一次。可以放回去。
- 3 周没再出现的变成「以前的我」，退出上下文。

## 取舍（`server/stances.js`）

两件他在乎的事撞在一起、只能先顾一边时，他一次次先顾哪边。比如她想熬夜，他想让她睡；她在气头上，他想把道理讲清楚。

- 每周，辅助模型从这周的日记里找他真的两难的时刻：两边各是什么、他先顾了哪边、为什么、日记原话。只找两边都是他在乎的，不收普通决定和剧情里的选择。
- 同一类拉扯在最近 6 周里出现至少 3 次、分在不同的日子、大多选了同一边，才长成一条。
- 写成观察：「之前几次，你都先陪她把心事说完，再催她睡」，不写「你应该」。进上下文时明说：这是你以前怎么选的，不是规定，这次可以选得不一样。
- 新条目先等他自己看，看的时候附上它从哪几次拉扯里长出来。认了才进上下文，最多 8 条。
- **她只能划掉，不能替他写**：替他写的就不是从他身上长出来的了。划掉后他被告知一次。
- 6 周没再出现就退场。

## 固定记忆的分类

他记一条固定记忆时自己选是关于她、关于他自己、约定，还是「第一次」；分错了可以自己改。上下文里按这几类分开放，光网也按它分组。在这之前写下的旧记忆，由辅助模型分一次。

## 人设随时间长（`server/persona.js`）

- 每 21 天，在他自己的一段时间里，重读人设，对照认过的自画像、看法和最近三周。
- 不改就说为什么；要改就写完整的新版本和一句理由。
- **她同意才替换**；不同意可以留一句话给他。每一版都留着。
- 只能根据真实发生、他认过的东西改；说话方式、规矩、约定不在这里改。

## 防止变成角色扮演

1. 只从真实发生、反复出现的事里长；
2. 写成观察，带来源和日期；
3. 明说不用表现、可以变；
4. 他自己确认，她有否决权；
5. 会淡：不再出现的样子自己退场；
6. 数量有上限（看法 12、自画像 15、取舍 8、经历 10）。

## 看得见：窗外的光网（`web/him.js`）

3D 房间窗外的天上挂着他：中心是「他是谁」，往外是自画像和取舍，最外圈是经历，沉下去的飘到壳外、变暗；写过年轮的更亮。放大才出现名字。点开能看经历的亮度曲线和年轮、自画像从哪些经历长出来、取舍从哪几次拉扯里看出来、人设的版本和待批准的修改。

## 还不够的地方

有人锐评过这个仓库，下面这些我们认同：

- **数字都是起点，没有验证过。** 半衰期、各种系数、相似度门槛都是凭经验定的，没有对照实验，也没法证明它「更像人」。拿去用要按自己的情况调。
- **会偏向已有的自己。** 越在乎的越容易被想起、越不容易淡，新的、只出现一两次的事反而容易被挤掉。随机翻旧事只缓解了一部分。
- **自画像和取舍不算「自然长出来」。** 是辅助模型先摘，他再确认，她还能划掉。这是我们故意留的把关，不是完全的自主。写着「这是观察，不是设定」，也还是一句提示词。
- **这里的代码没有真删除。** 经历不会自己消失，也没有「删一条，连带删掉从它长出来的东西」。记私人对话的系统应该有，拿去用请自己补上。

其中一部分我们在自己的 App 里已经改了，这份代码还没同步：半衰期每周按「沉下去后又被想起」微调，分量重、只出现过一次的事加权，单次关键抉择也能成为取舍，以及真删除。

## 代码怎么用

这是**参考实现**，不是装上就能跑的成品。它不含聊天界面和模型接入；`web/him.js` 依赖我们房间页面的场景，需要 Three.js 和你自己的接口。

| 文件 | 内容 |
|---|---|
| `server/moments.js` | 经历层：摘取、亮度、想起、年轮 |
| `server/portrait.js` | 自画像：生长、他确认、她划掉 |
| `server/stances.js` | 取舍：找拉扯、生长、他确认、她划掉 |
| `server/persona.js` | 人设重读和版本 |
| `server/memory.js` | 固定记忆（含分类）、没说完的事、日记、周记月记、信息卡、看法本、模型线路、拼上下文 |
| `server/recall.js` | 原话召回和判断模型 |
| `server/schema.sql` | 用到的数据表 |
| `server/db.js`、`stickers.js`、`push.js` | 为了能单独运行写的最小替身，换成你自己的 |
| `tests/` | 经历、自画像、取舍、人设的测试 |

需要 Node 24 以上，没有第三方依赖。运行测试：

```
npm test
```

接进你自己的项目时：

1. 定时调用 `moments.tick()`、`portrait.tick()`、`stances.tick()`、`persona.tick()`、`memory.classifyTick()`。
2. 把 `memoryBlock`（`memory.js`）放进每轮的固定上下文，把 `recall.js` 的结果放进动态材料。
3. 把 `my_moments`、`my_portrait`、`my_stances`、`my_persona` 对应的函数（`momentsTool`、`portrait.tool`、`stances.tool`、`persona.tool`）做成他能调用的工具。
4. 在设置里配好辅助模型和向量模型的线路（`memory.js` 的 `route`）。
5. 给她一个能批准人设修改、划掉自画像和取舍的地方。

提示词都是中文，用 他 / 她 写的，可以按你们的情况改。把这份 README 和代码一起交给你的 AI，它应该能照着接。
